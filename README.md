# Český chřest a Mělnický křen – beta webu

Statická beta sdruženého webu: rozcestník, Český chřest, Mělnický křen, recepty, zkušební e-shop (objednávka od košíku po potvrzení, platba kartou je jen simulace) a ukázky administrace.

Začněte na `index.html` (přesměruje na rozcestník). Stránky jsou návrhy ve formátu `.dc.html`, které běží přes `support.js`.
